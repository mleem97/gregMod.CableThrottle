# Quickstart — gregMod.CableThrottle

> gregMod.CableThrottle

Repo: [https://github.com/mleem97/gregMod.CableThrottle](https://github.com/mleem97/gregMod.CableThrottle) · Version: `0.1.0` · License: Apache-2.0.

## 1. Clone

```bash
git clone https://github.com/mleem97/gregMod.CableThrottle.git
cd gregMod.CableThrottle
```

## 2. Build / Start

Depending on your tech stack, choose **one** path:

```bash
# .NET
dotnet build -c Release
dotnet run --project src/

# Node / pnpm
pnpm install
pnpm build
pnpm start

# Python
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python -m <modul>
```

## 3. Test

```bash
dotnet test            # .NET
pnpm test              # Node
pytest                 # Python
```
